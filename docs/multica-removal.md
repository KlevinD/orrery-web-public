# Multica 残留实现替换

范围：Web / Go 服务端；不修改桌面客户端功能，不处理 IRIS。

本次依据现有 Orrery 的功能契约重新实现提及解析、Local/S3 存储和下载头处理，移除对应的旧实现及可能随其迁入的测试；保留通用接口与历史数据协议。Web 消息继续使用已接入的 AgentCore 事件接口，未新增 Multica 外部服务或运行依赖。实现与兼容约束见[自有基础设施说明](../orrery_v2/docs/runtime/owned-infrastructure.md)。

被替换的实现为 `mention_parser.go`、`filestore/local.go`、`filestore/s3.go` 和 `filestore/util.go`。新实现使用线性链接扫描、Go `os.Root` 目录隔离、成对文件发布与回滚、标准 MIME 头格式化及官方 AWS SDK。此次替换是实现和测试的更换，不以改名或删除来源注释作为剥离依据。

早期要求复制第三方源码的设计指引及生成副本已从发行工作树退役；原文、摘要和路径清单保存在私有审查材料，Git 历史也保持原样。拟公开发行继续使用审查后的快照，不直接公开包含旧代码的完整私有历史。

兼容性验证先在新实现上运行旧测试，再换成独立编写的回归测试。后者覆盖历史文件/元数据、五类提及与消息业务、路径和符号链接边界、上传失败/回滚、并发读取、HTTP Range、S3 分页、取消及错误传播。
