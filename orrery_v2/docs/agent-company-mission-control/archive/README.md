# Agent Company Archive

This directory keeps superseded, generated, or historical Agent Company / Mission Control documents.

## Contents

- `pre-saas-planning/` keeps early product strategy drafts, raw conversation summaries, and snapshot gap analyses created before the SaaS-first direction was selected.
- `generated/` keeps PDFs, HTML bundles, combined markdown, and scripts used to generate historical report artifacts.
- `废弃商业计划/` keeps explicitly discarded business plan drafts.
