# Stage 0 BDD 覆盖矩阵

本文把 [stage-0-bdd.md](./stage-0-bdd.md) 中的验收场景映射到建议测试、审计证据和可复用实现来源。它不是替代 BDD，而是实现完成时的验收索引。

状态含义：

```text
PENDING：尚未实现或尚未确认测试。
TEST：需要自动化测试证明。
STATIC：需要静态依赖或代码扫描证明。
AUDIT：需要人工审计或文档证据证明。
```

## 完成审计命令

实现完成后建议运行：

```powershell
go test ./internal/platform/...
go test ./...
rg "internal/(agent|mission|app|transport)" orrery_v2/internal/platform
rg "os\\.(Getenv|LookupEnv|Environ)" orrery_v2/internal | Select-String -NotMatch "internal/platform/(config|secret)"
rg "fmt\\.Print" orrery_v2/internal
```

预期：

```text
platform 测试全部通过。
全仓 Go 测试全部通过。
platform 不 import 业务目录。
业务模块不直接读取环境变量；`internal/platform/config` 是受控配置 env 入口，`internal/platform/secret` 是受控 secret env provider 入口。
业务模块不使用 fmt.Print 作为日志。
```
