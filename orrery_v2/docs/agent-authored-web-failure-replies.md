# 网页失败由 Agent 回答

网页抓取或搜索超时是工具结果，由 Agent 读取并向用户解释。Agent 可以改用其他可用来源，或说明哪些资料未取得、哪些结论无法确认。工具的失败状态和错误继续保留，不能将未访问的页面描述为已核实。

讨论服务允许包含网页工具失败的 Agent 最终回答正常保存、投递，不再仅因此将整轮回答判为编排失败。没有最终回答、工具仍在运行、权限不符及未完成的 Mission 状态转换仍由现有机制处理。

微信网关不再在重试耗尽时发送固定失败代答。真正的处理或投递失败仍保留重试、幂等和死信记录，并继续处理后续消息；不会因为取消提示而将失败任务标成成功。

网页失败处理规则随每一轮运行上下文提供，已有 PI 会话恢复后同样生效。此规则通过共享讨论运行时接入，不依赖未来自研循环。
