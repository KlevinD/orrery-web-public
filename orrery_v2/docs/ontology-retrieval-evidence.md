# Retrieval evidence and memory eligibility

本轮把 Semantica 对标中发现的普通记忆资格缺口和来源元数据缺口接到实际检索入口。语义判断继续由模型完成，宿主负责授权、记录状态、版本和输出边界；不增加人工审核。

## 记忆资格

`memory/core.RetrievalEligible` 是普通摘要、直接压缩和 PageIndex 记忆召回的共同检查：已禁用、未来生效、提议中、归档、删除和匿名化的记录不进入上下文。过滤发生在排序和最终条数限制之前。PageIndex 在 50 条上限内多取候选，避免失效的高分记录占满最终结果。

`ExpiresAt` 延续原有保留策略，**不是业务断言的 valid-to**。达到期限、正常敏感级别且没有引用的记录立即退出检索，随后由既有生命周期清扫器归档；仍有引用或有敏感性保留例外的记录继续作为 `historical_record` 提供。查询不删除原记录，也不依据 `LineageRefs` 或引用关系推定逻辑依赖。个人长期偏好仍使用其既有严格源记录检查，另在返回前复核偏好记录与当前档案授权。

## 统一证据协议

知识搜索结果的可选 `evidence`、记忆摘要的 `evidence[]` 使用 `orrery.retrieval-evidence.v1`。协议经 MCP `memory_search`、讨论上下文、Agent 记忆绑定和执行环境上下文传递到模型；HTTP/OpenAPI 和 TypeScript 类型同时更新。

| 字段 | 含义 |
| --- | --- |
| `purpose` | `material` 原文材料、`memory_record` 记忆记录、`historical_record` 保留的历史记录 |
| `truth_state` | `unknown` 未做事实真值证明；`disputed` 记忆记录声明了矛盾信号，仍需模型处理 |
| `source.kind/id/container_id/provider_id` | 区分 Orrery 记录、所属档案/知识库和 PageIndex 文档身份 |
| `source.version` | 宿主读取到的记录或目录元数据指纹；不冒充 PageIndex 语义修订号 |
| `source_state` | `record_snapshot` 仅压缩输入快照、`record_verified` 返回前读回记录、`catalog_verified` 目录匹配、`unversioned` 未能匹配版本 |
| `candidate_hash` | 知识片段内容与身份指纹，不包含重排分数 |
| `access_hash` | 本次主体与档案/知识库授权输入的指纹 |
| `valid_from/retention_until` | 记忆生效起点和保留期限，二者不得混为业务有效区间 |
| `assertions` | 记忆中的事实、偏好、决策各自的身份及文本哈希；不重复原文、不泄漏矛盾引用的私有 ID |
| `checked_at/input_hash` | 宿主检查时间与稳定输入指纹；检查时间不制造新的来源版本 |

知识搜索保留授权范围内的原文，包括叙述过去情况的材料。知识库目录匹配不证明远程片段来自该目录修订，更不证明整篇文字当前为真；因此这些结果始终标记 `material/unknown`。未匹配的旧文档可以返回，但必须是 `unversioned`，不能伪造修订号。已进入删除状态的目录文档和越过请求知识库范围的结果被排除。

记忆矛盾标记是记录级信号，协议不会自行裁决哪个陈述正确，也不把一个文档或一条记忆的所有陈述视为同一业务事实。

## 返回边界与缓存

普通摘要和语义召回在输出前重新读取所用记忆，比较完整记录指纹并复核档案授权。知识搜索在重排前检查候选、在重排后重新读取知识库、授权绑定和可匹配目录文档；来源改写、删除或撤权导致 `retrieval source or access changed; retrieve again`，不返回旧上下文。

重排器只可选择候选和修改分数，不能引入新身份、改写片段或提供可信校验标记；即使重排器原地修改输入，返回内容也必须对应事先保留的候选副本。传给重排器的检查时间被清零，避免同一来源仅因新时间戳而打散既有影子缓存；返回时间戳和证据由宿主重新生成。记忆摘要 ID 纳入来源版本，避免摘要文字相同、实际记录已改写时复用旧 ID。

知识搜索保留原有的超时部分结果行为；仅在请求已经超过截止时间时，为每个校验阶段提供最多 250ms 的独立预算。主动取消不会绕过取消状态。检查以查询结束时的读边界为准，不冻结之后的来源或权限变更；实际写入继续使用原有事务、幂等和提交围栏。

## 仍需继续对标

本协议没有把原文搜索升级为经过真值证明的当前事实搜索。完整的 claim/support 映射、显式 AND/OR 逻辑依赖、独立支持失效后的证明重算，以及证明与来源修订之间的原子快照，仍需在后续实现。不能将 `catalog_verified`、记忆引用或本协议的宿主哈希当作这些能力已完成的证据。

PageIndex 旧目录身份的回查最多读取每库 500 条；超出可映射范围的旧结果保持 `unversioned`。既有 PageIndex 同步和生命周期清扫器负责索引收敛，本轮不新增事实索引或定时任务。
