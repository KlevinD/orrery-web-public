# 文档断言有效期与历史推理

文档实例的属性与关系分别携带业务有效期。模型从原文提取、消歧和判断冲突，宿主校验原文、权限、版本及时间边界，再以事务写入；无需人工审核。

## 两个时间坐标

- `business_as_of`：业务事实在何时成立。
- `known_at`：系统截至何时已记录这些事实、纠正和撤回。

新文档断言使用 `state_interval`。有效期是 `[from, until)` 半开区间；原文明确“含结束日”时，日期按明确的 IANA 时区转换为次日零点，保留夏令时日历语义。时间戳须含 RFC3339 偏移。可存储坐标范围为 1678—2261 年。

`Validity` 支持 `from`、`until`、`until_inclusive`、`timezone`、`quote`。边界和时区须有原文依据；缺少时区的日期不猜测。有效期按属性和关系设置，实体登记日期不会自动成为所有属性的有效期。

原文未声明业务起点时，记录 `business_time_unspecified=true`，不把入库时间当业务起点。`source_recorded_at`、`source_superseded_at`、`orrery_ingested_at` 均由宿主设置，模型无权填写。

## 当前状态与到期维护

每个文档订阅持久保存下一次生效或到期边界。既有观察循环将到期任务投递到 outbox，不新增 cron。调度游标与投递原子提交；重试使用不同投递 ID 和相同业务事件 ID，支持停机恢复及耗尽重试后的再次投递。

维护事务校验订阅版本、原文版本、计划哈希、来源权限和投影归属，重算当前实体、逐条断言状态和身份索引，同时排队模型复核及持续推理，最后保存持久回执。任何一步失败全部回滚；重复事件返回原回执；旧任务不能覆盖新计划。

当前推理在冲突检测和规则连接之前过滤时间。一个推导中的全部前提都须有效；不同推导可以独立保留同一结论。聚合的 `knowledge_entity.Properties` 仅用于展示，推理从实际有效断言重建属性，避免过期聚合值再次成为前提。身份登记键不参与业务推导。

观察戳和提交校验也包括时间资格的变化，因此即使边界任务延迟，过期前提仍会使原候选提交失效。实际关系撤回依赖既有持续推理与模型执行队列，属于异步完成。

冲突只比较当前有效断言。模型选定值的有效窗口覆盖同值支持的并集；一份支持到期不会提前取消其他有效支持。出现新的生效断言时重新交给模型判断，不由宿主选择竞争值。判断的版本及适用业务窗口随事实版本保留。

## 历史查询

`ontology_infer` / 推理评估接口同时提供 `business_as_of` 与 `known_at` 时创建历史运行。两个字段必须同时填写，`known_at` 不能晚于宿主当前时间；此模式不接受 `documents` 或 `previous_run_id`。

```json
{
  "tenant_id": "example-scope",
  "root_id": "example-document",
  "business_as_of": "2026-09-01T00:00:00+08:00",
  "known_at": "2026-10-01T00:00:00+08:00",
  "rules": []
}
```

历史子图有节点、边、事实、证据、读取次数与执行时间预算。历史资源以及对应的当前对象、当前来源都必须通过今天的授权和字段策略；过去可读不代表现在可读。时间字段被遮盖的断言不能进入推理。原文摘录、内部来源定位信息和未获授权的证据引用不会进入返回的推理上下文。

历史运行仅保存查询及推导记录，不进入当前候选会话，不创建写回提案，不能预览、应用、撤回当前关系，也不能与当前运行做候选生命周期比较。运行记录标记 `historical`，并返回 `history_limitations`。

## 迁移与范围

新增迁移 `0246_ontology_assertion_time` 创建边界任务和维护回执表。宿主管理的知识属性及关系升级到 `state_interval`；保留自定义字段、动作与租户定义。实体本身继续作为稳定身份登记。

文档时间协议进入观察戳与模型版本，旧订阅会重新提取；新提交拒绝旧协议计划，已提交请求仍可按原回执幂等重放。

没有版本历史的旧 static 文档断言不补造过去，历史查询排除并标注 `unversioned_legacy_assertions_excluded`。缺失业务起点、来源当前不可访问、其他 static 资源没有版本历史也分别标注限制。历史查询使用当前规则和权限，不声称恢复过去的规则版本、过去的权限或所有检索渠道的完整历史。

本轮不包含跨文档、记忆与检索的统一证据协议、实体合并拆分、完整 OWL 推理或通用自然语言时间推理。
