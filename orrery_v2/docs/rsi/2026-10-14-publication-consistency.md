# RSI 第二批实现：发布事务与审计一致性

本批修复已评估候选在发布过程中的并发覆盖风险、旧安装首次发布后丢失基线的问题，以及失败发布留下错误激活资格的问题。它补齐发布基础，不代表真实模型优化或递归改进实验已经完成。

## 发布边界

应用层仍要求持久化评估通过，且基线、候选、数据集、策略、裁判与证据满足现有门槛。随后调用 AtomicVersionedRegistry，在提交边界重新核对 active 与 target 的完整 DefinitionHash，包括包摘要和启用状态。即使版本号没有变化，内容变更也会令旧评估的提交返回冲突。

PlatformRegistry 在一个数据库事务中完成基线版本保留、active 切换、激活历史、审计事件与待转存标记的写入。PostgreSQL 使用数据库记录键锁协调注册、兼容更新、禁用、删除、候选登记及切换；active 更新同时使用完整持久化记录的条件更新。SQLite 使用事务隔离；独立连接的过期提交也不能覆盖已经完成的切换。

MemoryRegistry 在共享注册表锁下重新核对内容；审计钩子成功后才修改内存状态。应用层拒绝仅实现旧版本接口、缺少原子切换能力的注册表。服务实例自身的互斥锁不再承担跨进程一致性的保证。

旧安装只存在 active、没有版本表和激活表时，首次切换会在同一事务中保存完整基线和其激活资格。候选登记本身不授予激活资格。钩子错误、数据库提交错误或提交前取消，均不会遗留本次事务的 active、历史或审计写入。

禁用仍是 active 上的控制状态，不会修改归档包。回滚到曾经生效的版本会恢复该版本保存的定义，包括其启用状态；这是现有回滚语义。

## 审计转存

运行库与审计库可能分开，不能假设一个本地 SQL 事务覆盖两者。本批使用事务 outbox 模式：运行库中的 `resource_skill_version_audit_events` 保存提交事件，`resource_skill_version_audit_pending` 保存待转存标记，两者与版本切换同时提交。

发布返回成功表示版本及其审计事件已经提交，审计中心的列表可能稍后显示这条事件。不会因审计库暂时不可用而把已经提交的版本反向覆盖。事件包含固定审计 ID、原始时间、前后内容哈希、评估引用及操作人。

生产装配注册 `resource.skill_version_audits`，由现有平台 Sweeper 驱动转存。每轮读取最多 100 条待处理记录；失败保留记录并报错，游标避免失败的前一页阻挡后续事件。固定 ID 支持至少一次投递；相同 ID、相同内容可重试，不同内容返回冲突。转存成功才删除待处理标记，原始提交事件保留。

该转存任务负责审计可靠性，不是历史 cron 优化器，也不是 RSI 的改进触发器。队列与事件保留策略仍需后续运维设计；本批没有为审计日志增加自动删除策略。

## 验证

测试覆盖同版本内容变更、候选变化、已删除 Skill、两个服务与两个文件数据库连接的过期提交、失败钩子、提交失败、取消、旧安装首次晋级与回滚、禁用后的归档保留，以及真实运行库和审计库关闭重开后的转存恢复。

审计故障测试分别模拟写入前不可用和写入后丢失确认。恢复后同一事件只有一条，不能被相同 ID 的不同内容覆盖。生产接线测试通过真实平台 Sweeper 把晋级与回滚事件转存到真实审计 Store。

Windows 上 Skill、Resource Admin、Agent Core、Assembly、HTTP、MCP 的完整包测试及新增审计、生产接线测试通过；相关包与服务器的 go vet 通过。Linux 上 Skill、Resource Admin、Agent Core、Assembly、Operations 的完整包测试及 `-race` 检测全部通过；新增生产注册表、审计接线与服务器结构测试也通过。

重新核对并补齐 Git 基线源码后，完整 Windows `go test ./...` 仍有 159 个包通过、7 个包失败。部分测试需要当前源码副本未包含的部署和 OpenFGA 资料；其他失败涉及启动资料、Windows 路径与符号链接假设、既有覆盖豁免到期；服务器全包测试还达到 180 秒超时。不能把这些结果视为完整生产验证通过，也不能据此认定全部失败都是仓库代码缺陷。生产接线及提交记录见本次交付说明。

## 边界

兼容目录更新仍允许覆盖相同版本，完整哈希检查会拒绝失效评估的发布，但没有把所有管理编辑改造成不可变版本。已有历史中错误授予的激活资格也没有自动清洗，需要单独的数据审查。本批没有执行生产迁移、替换运行二进制或部署服务。

真实候选生成、隔离对照执行、独立裁判、底层事件反馈，以及改进器 O0/O1 在同预算和未见任务上的比较仍需实现和实测。测试评分只验证发布接线，不能作为性能改进证据。
