# Support

Start with the root [README](README.md), the [contribution guide](CONTRIBUTING.md)
and the release documentation under `docs/`.

Use an issue for a reproducible product or documentation problem. Use the
feature request form for a focused proposal. Do not include credentials,
customer data, private logs or security-sensitive details in an issue.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and use a
private reporting channel. Do not disclose a vulnerability in a public issue.

The Web/API source release is validated manually. The repository does not
promise automated CI, response-time guarantees or hosted service support.
